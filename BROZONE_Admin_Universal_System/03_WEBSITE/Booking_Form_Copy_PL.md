## Komunikaty walidacji

| Sytuacja | Tekst |
| --- | --- |
| Puste imię | Wpisz imię i nazwisko. |
| Zły telefon | Numer wygląda na niepełny — potrzebujemy 9 cyfr. |
| Zły e-mail | Sprawdź adres e-mail. |
| Brak zgody | Bez zgody na przetwarzanie danych nie możemy przyjąć zgłoszenia. |
| Brak opisu (tattoo) | Napisz kilka słów o pomyśle — tatuator musi wiedzieć, co przygotować. |
| Zajęty termin | Ten termin właśnie ktoś zajął. Wybierz inny. |
