# Puste ekrany

Każdy pusty ekran: **co to za miejsce → dlaczego jest puste → jeden przycisk**.

## Dashboard

```
Dzisiaj nie ma jeszcze żadnych wizyt.
Rezerwacje ze strony pojawią się tu automatycznie.
[ Dodaj wizytę ręcznie ]
```

## Rezerwacje — brak wyników filtrowania

```
Brak wizyt dla wybranych filtrów.
Zmień zakres dat albo wyczyść filtry.
[ Wyczyść filtry ]
```

## Rezerwacje — pusta baza

```
Nie masz jeszcze żadnych rezerwacji.
Pierwsze zgłoszenia pojawią się tutaj, gdy klienci zaczną się zapisywać przez stronę.
[ Dodaj pierwszą wizytę ]
```

## Kalendarz — dzień bez wizyt

```
Wolny dzień — nikt nie jest zapisany.
Kliknij dowolną godzinę w siatce, żeby dodać wizytę.
```

## Klienci

```
Nie masz jeszcze żadnych klientów.

[ Dodaj klienta ręcznie ]
```


## Pracownicy

```
[ Dodaj pracownika ]
```

```

```


## Widok pracownika (barber / tatuator / masażysta)

```
Dziś nie masz żadnych wizyt.
Wolny dzień.
```

## Log synchronizacji

```
Brak zapisów w historii.
Pojawią się tutaj po pierwszej zmianie w systemie.
```

## Zasady pisania pustych ekranów

1. Nigdy samo „Brak danych".
2. Maksymalnie dwa zdania.
3. Dokładnie jeden przycisk (albo zero, jeśli nie ma sensownego działania).
4. Bez ilustracji zajmujących pół ekranu — mała ikona wystarczy.
5. Ton spokojny: pusty ekran to normalny stan, nie awaria.
