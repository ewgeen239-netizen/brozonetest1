# Teksty panelu (PL)

## Menu boczne

```
Dashboard
Rezerwacje
Kalendarz
Klienci
Pracownicy
Usługi
Ustawienia
```

Bez skrótów i żargonu. „Sync", „Staff", „Booking" zostają tylko jako drobny podpis
pod nazwą po polsku — dla stylu, nie dla znaczenia.

## Etykiety pól

```
Imię i nazwisko        Telefon              E-mail
Data                   Godzina              Czas trwania
Usługa                 Specjalista          Kategoria
Cena                   Zadatek              Status
Notatka wewnętrzna     Źródło rezerwacji

Portfolio              Instagram            Konsultacja wymagana
```

## Potwierdzenia (okna)

| Sytuacja | Tytuł | Treść | Przyciski |
| --- | --- | --- | --- |
| Anulowanie wizyty | Anulować wizytę? | Klient nie dostanie automatycznego powiadomienia — zadzwoń do niego. | Anuluj wizytę / Wróć |
| Archiwizacja pracownika | Przenieść do archiwum? | Osoba zniknie z kalendarza i ze strony. Historia wizyt zostanie. | Przenieś / Wróć |
| Usunięcie klienta | Usunąć dane klienta? | Imię, telefon i e-mail zostaną usunięte na stałe. Wizyty zostaną bez danych osobowych. | Usuń dane / Wróć |
| Przeniesienie wizyty | Przenieść wizytę? | {klient} — {stara data} → {nowa data} | Przenieś / Wróć |

## Powiadomienia (toasty)

| Sytuacja | Tekst |
| --- | --- |
